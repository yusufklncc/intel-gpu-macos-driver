Safari on the GPU: the system-volume copyGPU'da Safari: sistem diski kopyası

GivesSağladığı
Safari on the B580; its pages draw correctly, filters included (tested on macOS 26.7.1)B580'de Safari; sayfaları filtreler dahil doğru çiziliyor (macOS 26.7.1'de denendi)
NeedsGerekenler
The driver; SecureBootModel = Disabled (stage 2, item 6)Sürücü; SecureBootModel = Disabled (2. aşama, 6. madde)
UndoGeri alma
The Driver page's Safari and WebKit removes it; a macOS update removes it tooSürücü sayfasındaki Safari ve WebKit ile kaldırılır; bir macOS güncellemesi de kopyayı siler

Recommended. Safari's GPU process may only load code from the system volume. Without this copy Safari runs on macOS's software path: slower, and some page elements with CSS colour filters are not drawn (a CoreGraphics problem without a Metal device; turning off GraphicsContext Filter Rendering in Safari > Settings > Feature Flags works around it; the tab appears after Advanced > Show features for web developers).

system-volume/ssv-install.sh copies the Metal driver there and blesses a new boot snapshot, as OpenCore Legacy Patcher's root patches do. It needs Misc > Security > SecureBootModel = Disabled (stage 2, item 6). Nothing else needs it. A macOS update removes it again (./ssv-install.sh --check says so; install it again: After a macOS update). Tested on macOS 26.7.1: Safari runs on the B580 and its pages draw correctly, filters included. Safari's GPU process cannot keep translated shaders between starts (its sandbox), so its first pages after each start wait a few seconds.

Önerilir. Safari'nin GPU süreci yalnızca sistem diskinden kod yükleyebiliyor. Bu kopya olmadan Safari, macOS'un yazılımla çizim yolunda çalışır: daha yavaştır ve CSS renk filtresi kullanan bazı sayfa öğeleri çizilmez (Metal aygıtı olmadığında CoreGraphics'te görülen bir sorun; Safari > Ayarlar > Özellik Bayrakları'nda GraphicsContext Filter Rendering kapatılınca düzelir; bu sekme, Gelişmiş > Web geliştiricileri için özellikleri göster açılınca görünür).

system-volume/ssv-install.sh, OpenCore Legacy Patcher'ın kök yamalarının yaptığı gibi Metal sürücüsünü sistem diskine kopyalar ve yeni bir açılış anlık görüntüsü oluşturur. Misc > Security > SecureBootModel = Disabled gerekir (2. aşama, 6. madde). Bu ayar başka hiçbir şey için gerekmiyor. Bir macOS güncellemesi bu kopyayı siler (./ssv-install.sh --check bunu bildirir; kopyayı yeniden kurun: macOS güncellemesinden sonra). macOS 26.7.1'de denendi: Safari B580'de çalışıyor ve sayfaları filtreler dahil doğru çiziliyor. Safari'nin GPU süreci, sandbox nedeniyle çevrilmiş shader'ları Safari'nin bir çalışmasından ötekine saklayamıyor; bu yüzden Safari her açıldığında ilk sayfalar birkaç saniye bekletir.

With the app: the Driver page's Safari and WebKit installs, checks and removes the copy and tells when a macOS update removed it; the EFI page sets SecureBootModel to Disabled (backed up, undoable).

Uygulamayla: Sürücü sayfasındaki Safari ve WebKit bölümü kopyayı kurar, denetler, kaldırır ve bir macOS güncellemesi onu sildiyse bunu bildirir; EFI sayfası SecureBootModel'i Disabled yapar (önce yedek alır, geri alınabilir).

In Terminal, in the package folder:

cd system-volume && ./ssv-install.sh          # read-only checks
sudo ./ssv-install.sh --apply

Terminal'de, paket klasöründe:

cd system-volume && ./ssv-install.sh          # yalnızca kontrol
sudo ./ssv-install.sh --apply
After an upgrade

When the system-volume copy of an earlier release is installed, install.sh --apply creates /Library/GPUBundles/NVMTLDriver.use-library, so that every process uses the /Library copy in the meantime. ssv-install.sh --apply removes it again once it has installed this package's copy (only the file install.sh made: one you made yourself stays, and the script says so). ./install.sh --status shows use_library (with use_library_by: install, user or none) and system_volume_state: pending between ssv-install.sh --apply and the restart, same after it. The app's Driver page shows the same states. This is from 0.1.6; with 0.1.5 and earlier the file had to be removed by hand (details).

Yükseltmeden sonra

Daha eski bir sürümün sistem diski kopyası kuruluysa install.sh --apply, bu arada bütün süreçler /Library kopyasını kullansın diye /Library/GPUBundles/NVMTLDriver.use-library dosyasını oluşturur. ssv-install.sh --apply, bu paketin kopyasını kurduktan sonra dosyayı kendisi siler (yalnızca install.sh'in oluşturduğu dosyayı siler; dosyayı siz oluşturduysanız yerinde kalır ve betik bunu bildirir). ./install.sh --status, use_library (use_library_by ile: install, user ya da none) ve system_volume_state değerlerini gösterir: ssv-install.sh --apply ile yeniden başlatma arasında pending, sonra same. Uygulamanın Sürücü sayfası da aynı durumları gösterir. Bu davranış 0.1.6'dan itibaren geçerli; 0.1.5 ve öncesinde dosyanın elle silinmesi gerekiyordu (ayrıntılar).

OpenGL through ZinkZink ile OpenGL

GivesSağladığı
LWJGL 3 Java games (Minecraft Java 1.13 and later) through Mesa's zink, straight to the driver's VulkanLWJGL 3 Java oyunları (Minecraft Java 1.13 ve sonrası) için Mesa'nın zink'i üzerinden doğrudan sürücünün Vulkan'ı
NeedsGerekenler
The driver and intelxe_surfvram=2 (stage 2)Sürücü ve intelxe_surfvram=2 (2. aşama)
UndoGeri alma
--global off switches back, --undo removes it--global off eski hâline döndürür, --undo kaldırır

macOS's own OpenGL runs on top of Metal and is slow on this driver. LWJGL 3 Java games (Minecraft Java 1.13 and later) can use Mesa's zink instead, which turns OpenGL straight into Vulkan for the driver. Only applications that open OpenGL through GLFW/LWJGL use it; everything else stays on Apple's OpenGL. It needs the driver installed and intelxe_surfvram=2 (stage 2).

macOS'un kendi OpenGL'i Metal'in üzerinde çalışıyor ve bu sürücüde yavaş. LWJGL 3 Java oyunları (Minecraft Java 1.13 ve sonrası) bunun yerine Mesa'nın zink'ini kullanabilir: zink, OpenGL çağrılarını doğrudan sürücünün Vulkan'ına çeviriyor. Zink'i yalnızca OpenGL'i GLFW/LWJGL ile açan uygulamalar kullanır; geri kalan her şey Apple'ın OpenGL'inde kalır. Sürücünün kurulu olması ve intelxe_surfvram=2 ayarının yapılmış olması gerekir (2. aşama).

The IntelXe Manager app's OpenGL (Zink) page installs it and turns it on.

IntelXe Manager'ın OpenGL (Zink) sayfasından kurup açabilirsiniz.

In Terminal:

cd ~/Downloads
curl -LO https://github.com/yusufklncc/intel-gpu-macos-driver/releases/download/v0.1.6/intel-gpu-macos-driver-0.1.6-zink-gl.zip
ditto -x -k intel-gpu-macos-driver-0.1.6-zink-gl.zip .
cd intel-gpu-macos-driver-0.1.6-zink-gl
sudo ./install.sh                # /Library/IntelXe/GL and the Vulkan loader; backs up what it replaces
./install.sh --test              # a GL context through zink on the B580
sudo ./install.sh --global on    # every LWJGL 3 application started afterwards uses zink

--global off switches back, --undo removes it; README.md in the zip has the rest.

Terminal'de:

cd ~/Downloads
curl -LO https://github.com/yusufklncc/intel-gpu-macos-driver/releases/download/v0.1.6/intel-gpu-macos-driver-0.1.6-zink-gl.zip
ditto -x -k intel-gpu-macos-driver-0.1.6-zink-gl.zip .
cd intel-gpu-macos-driver-0.1.6-zink-gl
sudo ./install.sh                # /Library/IntelXe/GL ve Vulkan yükleyicisi; değiştirdiklerini yedekler
./install.sh --test              # B580'de zink üzerinden bir GL bağlamı açar
sudo ./install.sh --global on    # bundan sonra açılan bütün LWJGL 3 uygulamaları zink'i kullanır

--global off geri alır, --undo kaldırır; ayrıntılar zip'teki README.md'de.

Experimental: native OpenGL applications. A native macOS OpenGL application (CGL/NSOpenGL) can go through zink too, one application at a time: ./cglzink-app.sh add /Applications/X.app makes ~/Applications/X (zink).app (the zip's README.md, "Native OpenGL applications"); GZDoom ran at about 1910 fps that way, against about 1600 on Apple's OpenGL. Or every such application at once with an experimental switch, off by default: sudo ./install.sh --global-gl on, or the IntelXe Manager Zink page, which also keeps the list of applications that use zink or stay on Apple's OpenGL. That switch inserts a library into every application the session starts: turn it off (sudo ./install.sh --global-gl off) before you delete /Library/IntelXe/GL by hand, because a missing inserted library stops every application from starting. No IOSurface drawing (browsers) or CGL pbuffers through zink yet.

Deneysel: yerel OpenGL uygulamaları. CGL/NSOpenGL kullanan yerel bir macOS uygulaması da zink'e geçebilir, her seferinde bir uygulama: ./cglzink-app.sh add /Applications/X.app, ~/Applications/X (zink).app uygulamasını oluşturur (zip'teki README.md, "Native OpenGL applications"); GZDoom bu yolla yaklaşık 1910 fps'de çalıştı, Apple'ın OpenGL'inde ise yaklaşık 1600 fps'de. Bu tür uygulamaların hepsini birden geçirmek için varsayılan olarak kapalı deneysel bir anahtar da var: sudo ./install.sh --global-gl on ya da IntelXe Manager'ın Zink sayfası; bu sayfa zink kullanan ve Apple'ın OpenGL'inde kalan uygulamaların listesini de tutuyor. Bu anahtar, oturumun başlattığı her uygulamaya bir kütüphane ekliyor: /Library/IntelXe/GL'yi elle silmeden önce onu kapatın (sudo ./install.sh --global-gl off), çünkü eklenen kütüphane eksik olursa hiçbir uygulama açılmaz. Zink üzerinden IOSurface'e çizim (tarayıcılar) ve CGL pbuffer'ları henüz desteklenmiyor.

A launcher that macOS reopens by itself at login can start before the setting is in place and then runs on Apple's OpenGL: quit it and start it again (Java prints "Picked up JAVA_TOOL_OPTIONS" when zink is on).

macOS'un oturum açılışında kendiliğinden yeniden açtığı bir başlatıcı, ayar devreye girmeden başlayıp Apple'ın OpenGL'inde çalışabilir: başlatıcıdan çıkıp yeniden açın (zink açıkken Java "Picked up JAVA_TOOL_OPTIONS" yazar).

Vulkan for Windows games in Wine (experimental)Wine'daki Windows oyunları için Vulkan (deneysel)

Not yet tried with Wine on the hardware.

Donanımda Wine ile henüz denenmedi.

GivesSağladığı
The driver's own Vulkan (ANV) for DXVK and vkd3d-proton, one game at a timeDXVK ve vkd3d-proton için sürücünün kendi Vulkan'ı (ANV), her seferinde tek bir oyunda
NeedsGerekenler
The driver, a 64-bit Wine prefix and the optional -vulkan.zipSürücü, 64 bit bir Wine öneki ve isteğe bağlı -vulkan.zip
UndoGeri alma
$V prefix-restore ~/.wine, then sudo ./install.sh --undo$V prefix-restore ~/.wine, sonra sudo ./install.sh --undo

Wine runs Direct3D games through DXVK (Direct3D 8-11) and vkd3d-proton (Direct3D 12), which speak Vulkan; on macOS that Vulkan is normally MoltenVK, which translates it again into Metal. The optional -vulkan.zip (when the release has it) gives them the driver's own Vulkan (ANV) instead, one game at a time: only what you start through intelxe-vk run uses it, and Wine, its MoltenVK and the driver stay as they are. It needs the driver installed and a 64-bit Wine prefix; intelxe-vk check tells whether your Wine build can use it. IntelXe Manager's Zink page installs, tests and removes it too.

Wine, Direct3D oyunlarını Vulkan kullanan DXVK (Direct3D 8-11) ve vkd3d-proton (Direct3D 12) ile çalıştırır; macOS'ta bu Vulkan normalde MoltenVK'dır ve o da Vulkan'ı bir kez daha Metal'e çevirir. İsteğe bağlı -vulkan.zip (sürümde varsa) bunların yerine sürücünün kendi Vulkan'ını (ANV) kullandırır, her seferinde tek bir oyunda: onu yalnızca intelxe-vk run ile başlattığınız program kullanır; Wine, Wine'ın MoltenVK'sı ve sürücü olduğu gibi kalır. Sürücünün kurulu olması ve 64 bit bir Wine öneki gerekir; Wine derlemenizin bunu kullanıp kullanamayacağını intelxe-vk check söyler. IntelXe Manager'ın Zink sayfası da bu paketi kurar, dener ve kaldırır.

cd ~/Downloads
ditto -x -k intel-gpu-macos-driver-0.1.6-vulkan.zip .
cd intel-gpu-macos-driver-0.1.6-vulkan
sudo ./install.sh                   # /Library/IntelXe/Vulkan; backs up what it replaces
./install.sh --test                 # a window with 120 frames through the provider: PASS
V=/Library/IntelXe/Vulkan/bin/intelxe-vk
$V check "/Applications/Wine Stable.app"   # which Vulkan library that Wine opens; your prefixes
$V fetch                            # downloads DXVK and vkd3d-proton (pinned versions, checksums checked)
$V prefix-install ~/.wine           # their DLLs into the prefix; the prefix's own are kept
WINEPREFIX=~/.wine $V run wine game.exe
cd ~/Downloads
ditto -x -k intel-gpu-macos-driver-0.1.6-vulkan.zip .
cd intel-gpu-macos-driver-0.1.6-vulkan
sudo ./install.sh                   # /Library/IntelXe/Vulkan; değiştirdiklerini yedekler
./install.sh --test                 # sağlayıcı üzerinden 120 karelik bir pencere: PASS
V=/Library/IntelXe/Vulkan/bin/intelxe-vk
$V check "/Applications/Wine Stable.app"   # o Wine'ın açtığı Vulkan kitaplığı; önekleriniz
$V fetch                            # DXVK ve vkd3d-proton'u indirir (sabit sürüm, sağlama toplamı denetimli)
$V prefix-install ~/.wine           # DLL'leri öneke kurar; önekin kendi DLL'leri saklanır
WINEPREFIX=~/.wine $V run wine oyun.exe

$V prefix-restore ~/.wine gives the prefix Wine's own Direct3D back, sudo ./install.sh --undo removes the rest. fetch needs zstd for vkd3d-proton's archive (brew install zstd). The zip's README.md has the details and the limits (32-bit games and HDR untested; dxvk.conf in the prefix turns two DXVK descriptor features off on purpose).

$V prefix-restore ~/.wine öneki yeniden Wine'ın kendi Direct3D'sine döndürür, sudo ./install.sh --undo da gerisini kaldırır. fetch, vkd3d-proton'un arşivini açmak için zstd ister (brew install zstd). Ayrıntılar ve sınırlar zip'teki README.md'de (32 bit oyunlar ve HDR denenmedi; önekteki dxvk.conf, DXVK'nın iki descriptor özelliğini bilerek kapatır).

HiDPI modes (display scaling)HiDPI modları (ekran ölçeklendirme)

GivesSağladığı
Sharp "looks like" sizes in System Settings > Displays, at the monitor's full refresh rateSistem Ayarları > Ekranlar'da keskin "gibi görünür" boyutlar, monitörün tam yenileme hızında
NeedsGerekenler
The driver and a restart; tested on a 2560x1440 monitor onlySürücü ve yeniden başlatma; yalnızca 2560x1440 bir monitörde denendi
UndoGeri alma
sudo ./hidpi.sh --off (takes back only what --on wrote), or the Display pagesudo ./hidpi.sh --off (yalnızca --on'un yazdıklarını geri alır) ya da uygulamanın Ekran sayfası

Like display scaling on Windows: System Settings > Displays then offers "looks like" sizes (Larger Text ... More Space) that draw text and windows sharp at a larger size. On a 2560x1440 monitor they are 2048x1152, 1920x1080, 1706x960, 1600x900 and 1280x720. They run at the monitor's full refresh rate (180 Hz and Variable on the test monitor): macOS draws at twice the size and the GPU scales each frame down to the panel. They are off unless turned on.

Windows'taki ekran ölçeklendirmesine benzer: Sistem Ayarları > Ekranlar, yazıyı ve pencereleri daha büyük ama keskin gösteren "gibi görünür" boyutlar sunar (Daha Büyük Metin ... Daha Fazla Alan). 2560x1440 bir monitörde bunlar 2048x1152, 1920x1080, 1706x960, 1600x900 ve 1280x720. Bu boyutlar monitörün tam yenileme hızında çalışır (test monitöründe 180 Hz ve Değişken): macOS görüntüyü iki kat büyük çizer, GPU da her kareyi panelin çözünürlüğüne küçültür. Siz açmadıkça kapalıdırlar.

The IntelXe Manager app's Display page turns them on and off.

IntelXe Manager'ın Ekran sayfasından açıp kapatabilirsiniz.

In Terminal, in the package folder:

./hidpi.sh               # what is set now
sudo ./hidpi.sh --on     # NVRAM intelxefb-hidpi=1, a display override with the HiDPI sizes, DisplayResolutionEnabled
sudo ./hidpi.sh --off    # takes back only what --on wrote

Terminal'de, paket klasöründe:

./hidpi.sh               # şu an ne ayarlı
sudo ./hidpi.sh --on     # NVRAM'de intelxefb-hidpi=1, HiDPI boyutlarını içeren bir ekran ayarı, DisplayResolutionEnabled
sudo ./hidpi.sh --off    # yalnızca --on'un yazdıklarını geri alır

Restart after either, then choose a size in System Settings > Displays. The override goes where other HiDPI tools put theirs (/Library/Displays/Contents/Resources/Overrides); if your monitor already has one from another tool (one-key-hidpi and the like), hidpi.sh leaves it alone and stops: remove it first. Sizes for monitors other than 2560x1440 are untested. A size that leaves the screen black: HiDPI problems.

Hangisini çalıştırırsanız çalıştırın ardından yeniden başlatın, sonra Sistem Ayarları > Ekranlar'dan bir boyut seçin. Ekran ayarı, diğer HiDPI araçlarının kullandığı yere yazılır (/Library/Displays/Contents/Resources/Overrides); monitörünüz için başka bir aracın (one-key-hidpi vb.) yazdığı bir ayar zaten varsa hidpi.sh ona dokunmaz ve durur: önce o ayarı kaldırın. 2560x1440 dışındaki monitörlerde boyutlar denenmedi. Ekranı siyah bırakan bir boyut seçtiyseniz: HiDPI sorunları.

The menu bar itemMenü çubuğu öğesi

GivesSağladığı
Frames, the GPU clock and temperature, the display sizes to switch with one click, game modeKare hızı, GPU saati ve sıcaklığı, tek tıkla değiştirilen ekran boyutları, oyun modu
NeedsGerekenler
IntelXe Manager: Show in the menu bar on its Monitor pageIntelXe Manager: İzleme sayfasındaki Menü çubuğunda göster
UndoGeri alma
Turn Show in the menu bar offMenü çubuğunda göster seçeneğini kapatın

Part of IntelXe Manager, off unless turned on: Show in the menu bar on the Monitor page; the setup assistant's last page offers it with the other extras. It shows frames, the GPU clock and temperature at a glance, the main display's "looks like" sizes at the current refresh rate (the HiDPI ones included) to switch with one click, and game mode: on or off, and the app in front counted as a game. Open at login on the Power and app page keeps it there.

Game mode, off unless turned on: while a game (an app in the games category, or one added from the menu bar item) is in front, the GPU's lowest clock goes up, 2400 MHz by default.

IntelXe Manager'ın bir parçası; siz açmadıkça kapalı kalır: İzleme sayfasındaki Menü çubuğunda göster. Kurulum yardımcısının son sayfası da onu diğer eklerle birlikte sunuyor. Kare hızını, GPU saatini ve sıcaklığı bir bakışta gösterir; ana ekranın o anki yenileme hızındaki "gibi görünür" boyutları (HiDPI olanlar dahil) arasında tek tıkla geçmenizi sağlar; oyun modunu da gösterir: buradan açıp kapatabilir, öndeki uygulamayı oyun olarak sayabilirsiniz. Güç ve uygulama sayfasındaki Girişte aç, öğenin menü çubuğunda kalmasını sağlar.

Oyun modu da siz açmadıkça kapalıdır: bir oyun (oyun kategorisindeki bir uygulama ya da menü çubuğu öğesinden eklenen bir uygulama) öndeyken GPU'nun en düşük saat hızı yükseltilir, varsayılan olarak 2400 MHz'e.
