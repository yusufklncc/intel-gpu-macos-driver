Optional: OpenGL through zink

macOS's own OpenGL runs on top of Metal and is slow on this driver. LWJGL 3 Java games (Minecraft Java 1.13 and later) can use Mesa's zink instead, which turns OpenGL straight into Vulkan for the driver. Only applications that open OpenGL through GLFW/LWJGL use it; everything else stays on Apple's OpenGL. It needs the driver installed and intelxe_surfvram=2 (stage 2). The IntelXe Manager app's OpenGL (Zink) page installs it and turns it on, or in Terminal:

cd ~/Downloads
curl -LO https://github.com/yusufklncc/intel-gpu-macos-driver/releases/download/v0.1.4/intel-gpu-macos-driver-0.1.4-zink-gl.zip
ditto -x -k intel-gpu-macos-driver-0.1.4-zink-gl.zip .
cd intel-gpu-macos-driver-0.1.4-zink-gl
sudo ./install.sh                # /Library/IntelXe/GL and the Vulkan loader; backs up what it replaces
./install.sh --test              # a GL context through zink on the B580
sudo ./install.sh --global on    # every LWJGL 3 application started afterwards uses zink

--global off switches back, --undo removes it; README.md in the zip has the rest. Measured on the test machine (macOS 26.7.1, Minecraft 1.21.1 with Sodium and Iris, windowed, the same spot): with the BSL shader pack 197–205 fps with zink, 214–218 on the same PC under Windows with Intel's driver; without a shader pack 1400–1500 fps with zink against 700–1000 on Windows. Experimental: a native macOS OpenGL application (CGL/NSOpenGL) can go through zink too, one application at a time: ./cglzink-app.sh add /Applications/X.app makes ~/Applications/X (zink).app (the zip's README.md, "Native OpenGL applications"), or every such application at once with an experimental switch, off by default: sudo ./install.sh --global-gl on, or the IntelXe Manager Zink page, which also keeps the list of applications that use zink or stay on Apple's OpenGL. A launcher that macOS reopens by itself at login can start before the setting is in place and then runs on Apple's OpenGL: quit it and start it again (Java prints "Picked up JAVA_TOOL_OPTIONS" when zink is on).

Optional: HiDPI modes (display scaling)

Like display scaling on Windows: System Settings > Displays then offers "looks like" sizes (Larger Text ... More Space) that draw text and windows sharp at a larger size. On a 2560x1440 monitor they are 2048x1152, 1920x1080, 1706x960, 1600x900 and 1280x720. They run at the monitor's full refresh rate (180 Hz and Variable on the test monitor): macOS draws at twice the size and the GPU scales each frame down to the panel. They are off unless turned on. The IntelXe Manager app's Display page turns them on and off, or in Terminal, in the package folder:

./hidpi.sh               # what is set now
sudo ./hidpi.sh --on     # NVRAM intelxefb-hidpi=1, a display override with the HiDPI sizes, DisplayResolutionEnabled
sudo ./hidpi.sh --off    # takes back only what --on wrote

Restart after either, then choose a size in System Settings > Displays. The override goes where other HiDPI tools put theirs (/Library/Displays/Contents/Resources/Overrides); if your monitor already has one from another tool (one-key-hidpi and the like), hidpi.sh leaves it alone and stops: remove it first. If a size leaves the screen black, turn the modes off over SSH with sudo ./hidpi.sh --off and restart; Reset NVRAM in the OpenCore picker turns them off as well (the switch is the NVRAM variable).

İsteğe bağlı: zink ile OpenGL

macOS'un kendi OpenGL'i Metal'in üzerinde çalışıyor ve bu sürücüde yavaş. LWJGL 3 Java oyunları (Minecraft Java 1.13 ve sonrası) bunun yerine Mesa'nın zink'ini kullanabilir: zink OpenGL'i doğrudan sürücünün Vulkan'ına çeviriyor. Yalnızca OpenGL'i GLFW/LWJGL ile açan uygulamalar kullanır; geri kalan her şey Apple'ın OpenGL'inde kalır. Sürücünün kurulu ve intelxe_surfvram=2 ayarının açık olması gerekiyor (2. aşama). IntelXe Manager'ın OpenGL (Zink) sayfası kurar ve açar; ya da Terminal'de:

cd ~/Downloads
curl -LO https://github.com/yusufklncc/intel-gpu-macos-driver/releases/download/v0.1.4/intel-gpu-macos-driver-0.1.4-zink-gl.zip
ditto -x -k intel-gpu-macos-driver-0.1.4-zink-gl.zip .
cd intel-gpu-macos-driver-0.1.4-zink-gl
sudo ./install.sh                # /Library/IntelXe/GL ve Vulkan yükleyicisi; değiştirdiğini yedekler
./install.sh --test              # B580'de zink üzerinden bir GL bağlamı
sudo ./install.sh --global on    # bundan sonra açılan bütün LWJGL 3 uygulamaları zink kullanır

--global off geri alır, --undo kaldırır; ayrıntılar zip'teki README.md'de. Test makinesinde ölçüldü (macOS 26.7.1, Minecraft 1.21.1, Sodium ve Iris ile, pencereli, aynı nokta): BSL shader paketiyle zink'te 197–205 fps, aynı bilgisayarda Windows'ta Intel'in sürücüsüyle 214–218; shader paketi olmadan zink'te 1400–1500 fps, Windows'ta 700–1000. Deneysel: CGL/NSOpenGL kullanan yerel bir macOS uygulaması da tek tek zink'e geçebilir: ./cglzink-app.sh add /Applications/X.app ~/Applications/X (zink).app'i oluşturur (zip'teki README.md, "Native OpenGL applications") ya da varsayılan olarak kapalı deneysel bir anahtarla hepsi birden: sudo ./install.sh --global-gl on ya da IntelXe Manager'ın Zink sayfası; o sayfa zink kullanan ya da Apple'ın OpenGL'inde kalan uygulamaların listesini de tutuyor. macOS'un girişte kendiliğinden yeniden açtığı bir başlatıcı, ayar yerine oturmadan başlayıp Apple'ın OpenGL'inde kalabilir: kapatıp yeniden açın (zink açıkken Java "Picked up JAVA_TOOL_OPTIONS" yazar).

İsteğe bağlı: HiDPI modları (ekran ölçeklendirme)

Windows'taki ekran ölçeklendirmesi gibi: Sistem Ayarları > Ekranlar, yazıyı ve pencereleri daha büyük ama keskin çizen "gibi görünür" boyutlar sunar (Daha Büyük Metin ... Daha Fazla Alan). 2560x1440 bir monitörde bunlar 2048x1152, 1920x1080, 1706x960, 1600x900 ve 1280x720. Monitörün tam yenileme hızında çalışırlar (test monitöründe 180 Hz ve Değişken): macOS iki katı boyutta çizer, GPU her kareyi panelin boyutuna küçültür. Açılmadıkça kapalıdırlar. IntelXe Manager'ın Ekran sayfası açıp kapatır; ya da Terminal'de, paket klasöründe:

./hidpi.sh               # şu an ne ayarlı
sudo ./hidpi.sh --on     # NVRAM intelxefb-hidpi=1, HiDPI boyutlarıyla bir ekran ayarı, DisplayResolutionEnabled
sudo ./hidpi.sh --off    # yalnızca --on'un yazdıklarını geri alır

İkisinden sonra da yeniden başlatın, sonra Sistem Ayarları > Ekranlar'dan bir boyut seçin. Ekran ayarı, diğer HiDPI araçlarının kullandığı yere yazılır (/Library/Displays/Contents/Resources/Overrides); monitörünüz için başka bir aracın (one-key-hidpi vb.) yazdığı bir ayar zaten varsa hidpi.sh ona dokunmaz ve durur: önce onu kaldırın. Bir boyut ekranı siyah bırakırsa SSH'tan sudo ./hidpi.sh --off çalıştırıp yeniden başlatın; OpenCore menüsündeki Reset NVRAM de modları kapatır (anahtar NVRAM değişkenidir).
