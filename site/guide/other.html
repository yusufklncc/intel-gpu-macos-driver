The install refuses: SIP or AMFI not relaxedKurulum reddediyor: SIP ya da AMFI gevşetilmemiş

Stage 2 is not in effect: csr-active-config and amfi_get_out_of_my_way=0x1 must be set, and both csr-active-config and boot-args must be in NVRAM > Delete so that the new values replace the old ones (stage 2). Restart after changing them. ./install.sh alone checks this and changes nothing; the app's Overview shows the same.

2. aşama devrede değil: csr-active-config ve amfi_get_out_of_my_way=0x1 ayarlı olmalı, hem csr-active-config hem de boot-args NVRAM > Delete içinde olmalı ki yeni değerler eskilerin yerine geçsin (2. aşama). Değiştirdikten sonra yeniden başlatın. Yalnızca ./install.sh bunu denetler, hiçbir şeyi değiştirmez; uygulamanın Genel bakış sayfası da aynısını gösterir.

The app's EFI page finds no EFIUygulamanın EFI sayfası EFI bulamıyor

OpenCore did not record which EFI it booted from: it does that only when Misc > Security > ExposeSensitiveData includes 1. The app then lists the EFI partitions with their disk's name and size to choose from, or takes a folder you pick (Use an EFI folder…, for example a USB stick's). The stage-4 change also adds 1 to ExposeSensitiveData, so that the next boots record it. Disk numbers are never used: they change between boots.

OpenCore hangi EFI'den açıldığını kaydetmemiş: bunu yalnızca Misc > Security > ExposeSensitiveData 1'i içeriyorsa yapıyor. Uygulama o zaman seçmeniz için EFI bölümlerini diskin adı ve boyutuyla listeliyor ya da seçtiğiniz bir klasörü (Bir EFI klasörü kullan…, örneğin bir USB belleğinkini) kullanıyor. 4. aşama değişikliği ExposeSensitiveData'ya 1'i de ekliyor, böylece sonraki açılışlar bunu kaydediyor. Disk numaraları hiç kullanılmıyor: açılıştan açılışa değişiyorlar.

Windows: "running scripts is disabled"Windows: "running scripts is disabled"

Start IntelXe-EFI.ps1 from a PowerShell window with powershell -ExecutionPolicy Bypass -File .\IntelXe-EFI.ps1 (that one run only), and Unblock-File .\IntelXe-EFI.ps1 once for a file downloaded with a browser. Mounting an EFI partition needs administrator rights (Restart as administrator). Details: From Windows.

IntelXe-EFI.ps1'i bir PowerShell penceresinden powershell -ExecutionPolicy Bypass -File .\IntelXe-EFI.ps1 ile başlatın (yalnızca o çalıştırma için); tarayıcıyla indirilmiş bir dosya için bir kez Unblock-File .\IntelXe-EFI.ps1. Bir EFI bölümünü bağlamak yönetici hakları ister (Restart as administrator). Ayrıntılar: Windows'tan.

Other install.sh commandsinstall.sh'nin diğer komutları

In the package folder (the app's Driver page has the same as buttons): ./install.sh --status compares what is installed with this package and changes nothing. sudo ./install.sh --repair puts back installed files that differ from the package and leaves the last backup alone. sudo ./install.sh --uninstall removes the kexts and the Metal driver from /Library and keeps the backups; --undo instead goes back to what the last install replaced. After --uninstall, remove IntelXe.kext from the EFI before you reboot.

Paket klasöründe (uygulamanın Sürücü sayfasında aynıları düğme olarak var): ./install.sh --status kurulu olanı bu paketle karşılaştırır, hiçbir şeyi değiştirmez. sudo ./install.sh --repair kurulu dosyalardan paketle uyuşmayanları yeniden kopyalar, son yedeğe dokunmaz. sudo ./install.sh --uninstall kext'leri ve Metal sürücüsünü /Library'den siler, yedekleri bırakır; --undo ise son kurulumun değiştirdiklerini geri getirir. --uninstall'dan sonra, yeniden başlatmadan önce IntelXe.kext'i EFI'den çıkarın.

Undo everythingHer şeyi geri almak

sudo ./install.sh --undo, then reboot with IntelXe.kext and SSDT-ARCOFF.aml removed from the EFI. The EFI side: the app's EFI page (Undo), sudo ./efi.sh --undo, IntelXe-EFI.ps1's Undo last change..., or by hand; each undo goes one change further back. If you added them, also remove the system-volume copy (the Driver page's Safari and WebKit), the Zink package (sudo ./install.sh --undo in its folder, which turns --global-gl off first) and the HiDPI modes (sudo ./hidpi.sh --off). The stage 2 settings stay in config.plist until you change them back.

sudo ./install.sh --undo, sonra IntelXe.kext ve SSDT-ARCOFF.aml EFI'den çıkarılmış olarak yeniden başlatın. EFI tarafı: uygulamanın EFI sayfası (Undo), sudo ./efi.sh --undo, IntelXe-EFI.ps1'in Undo last change... düğmesi ya da elle; her geri alma bir değişiklik daha geriye gider. Eklediyseniz sistem diski kopyasını (Sürücü sayfasında Safari ve WebKit), Zink paketini (kendi klasöründe sudo ./install.sh --undo; önce --global-gl'u kendisi kapatır) ve HiDPI modlarını (sudo ./hidpi.sh --off) da kaldırın. 2. aşama ayarları siz geri değiştirene kadar config.plist'te kalır.
