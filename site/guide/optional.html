Safari on the GPU: the system-volume copyGPU'da Safari: sistem diski kopyası

GivesSağladığı
Safari on the B580; its pages draw correctly, filters included (tested on macOS 26.7.1)B580'de Safari; sayfaları filtreler dahil doğru çiziliyor (macOS 26.7.1'de denendi)
NeedsGerekenler
The driver; SecureBootModel = Disabled (stage 2, item 6)Sürücü; SecureBootModel = Disabled (2. aşama, 6. madde)
UndoGeri alma
The Driver page's Safari and WebKit removes it; a macOS update removes it tooSürücü sayfasındaki Safari ve WebKit ile kaldırılır; bir macOS güncellemesi de kopyayı siler

Recommended. Without this copy, Safari does not draw on the GPU. It is slower, and some page elements are not drawn.

Önerilir. Bu kopya olmadan Safari GPU'da çizmez. Daha yavaştır ve bazı sayfa öğeleri çizilmez.

With the app:

  1. On the EFI (OpenCore) page, press Turn Apple Secure Boot off, if it is not off yet. This sets SecureBootModel to Disabled. The app backs up the EFI first, and you can undo it.
  2. On the Driver page, under Safari and WebKit, press Install the system-volume copy.
  3. Restart.

Safari and WebKit also checks and removes the copy. It tells you when a macOS update removed it.

Uygulamayla:

  1. Henüz kapalı değilse EFI (OpenCore) sayfasında Apple Güvenli Önyüklemeyi kapat'a basın. Bu, SecureBootModel'i Disabled yapar. Uygulama önce EFI'nin yedeğini alır; değişikliği geri alabilirsiniz.
  2. Sürücü sayfasında, Safari ve WebKit altında Sistem birimi kopyasını kur'a basın.
  3. Yeniden başlatın.

Safari ve WebKit bölümü kopyayı denetler ve kaldırır da. Bir macOS güncellemesi kopyayı sildiyse bunu bildirir.

In Terminal, in the package folder:

  1. Set Misc > Security > SecureBootModel = Disabled in config.plist, if it is not set yet (stage 2, item 6).
  2. Check, then install the copy: 
    cd system-volume && ./ssv-install.sh          # read-only checks
sudo ./ssv-install.sh --apply
  3. Restart.

Terminal'de, paket klasöründe:

  1. Henüz ayarlı değilse config.plist'te Misc > Security > SecureBootModel = Disabled yapın (2. aşama, 6. madde).
  2. Önce denetleyin, sonra kopyayı kurun: 
    cd system-volume && ./ssv-install.sh          # yalnızca kontrol
sudo ./ssv-install.sh --apply
  3. Yeniden başlatın.

Safari's first pages after each start wait a few seconds.

A macOS update removes the copy. ./ssv-install.sh --check says so. Install it again: After a macOS update.

Safari her açıldığında ilk sayfalar birkaç saniye bekletir.

Bir macOS güncellemesi kopyayı siler. ./ssv-install.sh --check bunu bildirir. Kopyayı yeniden kurun: macOS güncellemesinden sonra.

Why Safari needs this copySafari bu kopyaya neden ihtiyaç duyuyor

Safari's GPU process may only load code from the system volume. system-volume/ssv-install.sh copies the Metal driver there and blesses a new boot snapshot, as OpenCore Legacy Patcher's root patches do.

That needs Misc > Security > SecureBootModel = Disabled. Nothing else needs it.

Safari's GPU process cannot keep translated shaders between starts (its sandbox). That is why its first pages after each start wait.

Safari'nin GPU süreci yalnızca sistem diskinden kod yükleyebiliyor. system-volume/ssv-install.sh, OpenCore Legacy Patcher'ın kök yamalarının yaptığı gibi Metal sürücüsünü sistem diskine kopyalar ve yeni bir açılış anlık görüntüsü oluşturur.

Bunun için Misc > Security > SecureBootModel = Disabled gerekir. Bu ayar başka hiçbir şey için gerekmiyor.

Safari'nin GPU süreci, sandbox nedeniyle çevrilmiş shader'ları Safari'nin bir çalışmasından ötekine saklayamıyor. İlk sayfaların beklemesinin nedeni bu.

Not installing the copy?Kopyayı kurmuyor musunuz?

Then Safari runs on macOS's software path. It is slower, and some page elements with CSS colour filters are not drawn. This is a CoreGraphics problem without a Metal device.

To work around it, turn off GraphicsContext Filter Rendering in Safari > Settings > Feature Flags. The tab appears after Advanced > Show features for web developers.

O zaman Safari, macOS'un yazılımla çizim yolunda çalışır. Daha yavaştır ve CSS renk filtresi kullanan bazı sayfa öğeleri çizilmez. Bu, Metal aygıtı olmadığında CoreGraphics'te görülen bir sorun.

Geçici çözüm: Safari > Ayarlar > Özellik Bayrakları'nda GraphicsContext Filter Rendering'i kapatın. Bu sekme, Gelişmiş > Web geliştiricileri için özellikleri göster açılınca görünür.

After an upgrade

When the system-volume copy of an earlier release is installed, install.sh --apply creates /Library/GPUBundles/NVMTLDriver.use-library, so that every process uses the /Library copy in the meantime. ssv-install.sh --apply removes it again once it has installed this package's copy (only the file install.sh made: one you made yourself stays, and the script says so). ./install.sh --status shows use_library (with use_library_by: install, user or none) and system_volume_state: pending between ssv-install.sh --apply and the restart, same after it. The app's Driver page shows the same states. This is from 0.1.6; with 0.1.5 and earlier the file had to be removed by hand (details).

Yükseltmeden sonra

Daha eski bir sürümün sistem diski kopyası kuruluysa install.sh --apply, bu arada bütün süreçler /Library kopyasını kullansın diye /Library/GPUBundles/NVMTLDriver.use-library dosyasını oluşturur. ssv-install.sh --apply, bu paketin kopyasını kurduktan sonra dosyayı kendisi siler (yalnızca install.sh'in oluşturduğu dosyayı siler; dosyayı siz oluşturduysanız yerinde kalır ve betik bunu bildirir). ./install.sh --status, use_library (use_library_by ile: install, user ya da none) ve system_volume_state değerlerini gösterir: ssv-install.sh --apply ile yeniden başlatma arasında pending, sonra same. Uygulamanın Sürücü sayfası da aynı durumları gösterir. Bu davranış 0.1.6'dan itibaren geçerli; 0.1.5 ve öncesinde dosyanın elle silinmesi gerekiyordu (ayrıntılar).

macOS's own OpenGL is slow on this driver. Minecraft Java (1.13 and later) and other LWJGL 3 Java games can use Mesa's zink instead. It needs the driver and intelxe_surfvram=2 (stage 2).

macOS'un kendi OpenGL'i bu sürücüde yavaş. Minecraft Java (1.13 ve sonrası) ve diğer LWJGL 3 Java oyunları bunun yerine Mesa'nın zink'ini kullanabilir. Sürücü ve intelxe_surfvram=2 ayarı gerekir (2. aşama).

  1. In IntelXe Manager, open the OpenGL (Zink) page.
  2. Press Install Zink.
  3. Under Every LWJGL application, press Use Zink for every LWJGL application.
  4. Start your game. Games you start after this use zink.
  1. IntelXe Manager'da OpenGL (Zink) sayfasını açın.
  2. Zink'i kur'a basın.
  3. Bütün LWJGL uygulamaları altında Bütün LWJGL uygulamalarında Zink kullan'a basın.
  4. Oyununuzu başlatın. Bundan sonra başlattığınız oyunlar zink'i kullanır.

In Terminal:

  1. Download and unpack the package: 
    cd ~/Downloads
curl -LO https://github.com/yusufklncc/intel-gpu-macos-driver/releases/download/v0.1.6/intel-gpu-macos-driver-0.1.6-zink-gl.zip
ditto -x -k intel-gpu-macos-driver-0.1.6-zink-gl.zip .
cd intel-gpu-macos-driver-0.1.6-zink-gl
  2. Install it: 
    sudo ./install.sh                # /Library/IntelXe/GL and the Vulkan loader; backs up what it replaces
  3. Test it: 
    ./install.sh --test              # a GL context through zink on the B580
  4. Turn it on: 
    sudo ./install.sh --global on    # every LWJGL 3 application started afterwards uses zink

--global off switches back, --undo removes it; README.md in the zip has the rest.

Game still on Apple's OpenGL? A launcher that macOS reopens by itself at login can start before the setting is in place. Quit it and start it again. Java prints "Picked up JAVA_TOOL_OPTIONS" when zink is on.

Oyun hâlâ Apple'ın OpenGL'inde mi? macOS'un oturum açılışında kendiliğinden yeniden açtığı bir başlatıcı, ayar devreye girmeden başlamış olabilir. Başlatıcıdan çıkıp yeniden açın. Zink açıkken Java "Picked up JAVA_TOOL_OPTIONS" yazar.

What zink does, and which applications use itZink ne yapar, hangi uygulamalar onu kullanır

macOS's own OpenGL runs on top of Metal. Zink turns OpenGL straight into Vulkan for the driver.

Only applications that open OpenGL through GLFW/LWJGL use it; everything else stays on Apple's OpenGL.

macOS'un kendi OpenGL'i Metal'in üzerinde çalışıyor. Zink, OpenGL çağrılarını doğrudan sürücünün Vulkan'ına çeviriyor.

Zink'i yalnızca OpenGL'i GLFW/LWJGL ile açan uygulamalar kullanır; geri kalan her şey Apple'ın OpenGL'inde kalır.

Native macOS OpenGL applications (experimental)Yerel macOS OpenGL uygulamaları (deneysel)

A native macOS OpenGL application (CGL/NSOpenGL) can go through zink too, one application at a time: ./cglzink-app.sh add /Applications/X.app makes ~/Applications/X (zink).app (the zip's README.md, "Native OpenGL applications").

Or every such application at once with an experimental switch, off by default: sudo ./install.sh --global-gl on, or the IntelXe Manager Zink page. That page also keeps the list of applications that use zink or stay on Apple's OpenGL.

Before you delete /Library/IntelXe/GL by hand, turn that switch off (sudo ./install.sh --global-gl off). The switch inserts a library into every application the session starts. If the inserted library is missing, no application starts.

No IOSurface drawing (browsers) or CGL pbuffers through zink yet.

CGL/NSOpenGL kullanan yerel bir macOS uygulaması da zink'e geçebilir, her seferinde bir uygulama: ./cglzink-app.sh add /Applications/X.app, ~/Applications/X (zink).app uygulamasını oluşturur (zip'teki README.md, "Native OpenGL applications").

Bu tür uygulamaların hepsini birden geçirmek için varsayılan olarak kapalı deneysel bir anahtar da var: sudo ./install.sh --global-gl on ya da IntelXe Manager'ın Zink sayfası. Bu sayfa zink kullanan ve Apple'ın OpenGL'inde kalan uygulamaların listesini de tutuyor.

/Library/IntelXe/GL'yi elle silmeden önce bu anahtarı kapatın (sudo ./install.sh --global-gl off). Anahtar, oturumun başlattığı her uygulamaya bir kütüphane ekliyor. Eklenen kütüphane eksik olursa hiçbir uygulama açılmaz.

Zink üzerinden IOSurface'e çizim (tarayıcılar) ve CGL pbuffer'ları henüz desteklenmiyor.

Vulkan for Windows games in Wine (experimental)Wine'daki Windows oyunları için Vulkan (deneysel)

Not yet tried with Wine on the hardware.

The driver's own Vulkan (ANV) for DXVK and vkd3d-proton, one game at a timeDXVK ve vkd3d-proton için sürücünün kendi Vulkan'ı (ANV), her seferinde tek bir oyunda
NeedsGerekenler
The driver, a 64-bit Wine prefix and the optional -vulkan.zipSürücü, 64 bit bir Wine öneki ve isteğe bağlı -vulkan.zip
UndoGeri alma
$V prefix-restore ~/.wine, then sudo ./install.sh --undo$V prefix-restore ~/.wine, sonra sudo ./install.sh --undo

Wine runs Direct3D games through DXVK and vkd3d-proton. The optional -vulkan.zip (when the release has it) gives them the driver's own Vulkan, one game at a time. It needs the driver and a 64-bit Wine prefix.

  1. Unpack and install the package: 
    cd ~/Downloads
ditto -x -k intel-gpu-macos-driver-0.1.6-vulkan.zip .
cd intel-gpu-macos-driver-0.1.6-vulkan
sudo ./install.sh                   # /Library/IntelXe/Vulkan; backs up what it replaces
  2. Test it: 
    ./install.sh --test                 # a window with 120 frames through the provider: PASS
  3. Check that your Wine build can use it. intelxe-vk check tells you. 
    V=/Library/IntelXe/Vulkan/bin/intelxe-vk
$V check "/Applications/Wine Stable.app"   # which Vulkan library that Wine opens; your prefixes
  4. Download DXVK and vkd3d-proton. This needs zstd for vkd3d-proton's archive (brew install zstd). 
    $V fetch                            # downloads DXVK and vkd3d-proton (pinned versions, checksums checked)
  5. Put their DLLs into your Wine prefix: 
    $V prefix-install ~/.wine           # their DLLs into the prefix; the prefix's own are kept
  6. Start the game through intelxe-vk run: 
    WINEPREFIX=~/.wine $V run wine game.exe

To undo: $V prefix-restore ~/.wine gives the prefix Wine's own Direct3D back, sudo ./install.sh --undo removes the rest.

With the app instead? IntelXe Manager's Zink page installs, tests and removes this package too.

Wine, Direct3D oyunlarını DXVK ve vkd3d-proton ile çalıştırır. İsteğe bağlı -vulkan.zip (sürümde varsa) bunlara sürücünün kendi Vulkan'ını kullandırır, her seferinde tek bir oyunda. Sürücünün kurulu olması ve 64 bit bir Wine öneki gerekir.

  1. Paketi arşivden çıkarıp kurun: 
    cd ~/Downloads
ditto -x -k intel-gpu-macos-driver-0.1.6-vulkan.zip .
cd intel-gpu-macos-driver-0.1.6-vulkan
sudo ./install.sh                   # /Library/IntelXe/Vulkan; değiştirdiklerini yedekler
  2. Deneyin: 
    ./install.sh --test                 # sağlayıcı üzerinden 120 karelik bir pencere: PASS
  3. Wine'ınızın bunu kullanıp kullanamayacağını denetleyin. Bunu intelxe-vk check söyler. 
    V=/Library/IntelXe/Vulkan/bin/intelxe-vk
$V check "/Applications/Wine Stable.app"   # o Wine'ın açtığı Vulkan kitaplığı; önekleriniz
  4. DXVK ve vkd3d-proton'u indirin. vkd3d-proton'un arşivini açmak için zstd gerekir (brew install zstd). 
    $V fetch                            # DXVK ve vkd3d-proton'u indirir (sabit sürüm, sağlama toplamı denetimli)
  5. DLL'lerini Wine önekinize kurun: 
    $V prefix-install ~/.wine           # DLL'leri öneke kurar; önekin kendi DLL'leri saklanır
  6. Oyunu intelxe-vk run ile başlatın: 
    WINEPREFIX=~/.wine $V run wine oyun.exe

Geri almak için: $V prefix-restore ~/.wine öneki yeniden Wine'ın kendi Direct3D'sine döndürür, sudo ./install.sh --undo da gerisini kaldırır.

Uygulamayla mı yapmak istiyorsunuz? IntelXe Manager'ın Zink sayfası da bu paketi kurar, dener ve kaldırır.

How this worksNasıl çalışıyor

DXVK (Direct3D 8-11) and vkd3d-proton (Direct3D 12) speak Vulkan. On macOS that Vulkan is normally MoltenVK, which translates it again into Metal. This package gives them the driver's own Vulkan (ANV) instead.

Only what you start through intelxe-vk run uses it. Wine, its MoltenVK and the driver stay as they are.

The zip's README.md has the details and the limits. dxvk.conf in the prefix turns two DXVK descriptor features off on purpose.

DXVK (Direct3D 8-11) ve vkd3d-proton (Direct3D 12) Vulkan kullanır. macOS'ta bu Vulkan normalde MoltenVK'dır ve o da Vulkan'ı bir kez daha Metal'e çevirir. Bu paket bunların yerine sürücünün kendi Vulkan'ını (ANV) kullandırır.

Onu yalnızca intelxe-vk run ile başlattığınız program kullanır. Wine, Wine'ın MoltenVK'sı ve sürücü olduğu gibi kalır.

Ayrıntılar ve sınırlar zip'teki README.md'de. Önekteki dxvk.conf, DXVK'nın iki descriptor özelliğini bilerek kapatır.

Like display scaling on Windows: System Settings > Displays then offers "looks like" sizes (Larger Text ... More Space). They draw text and windows sharp at a larger size, at the monitor's full refresh rate. They are off unless turned on.

Windows'taki ekran ölçeklendirmesine benzer: Sistem Ayarları > Ekranlar, "gibi görünür" boyutlar sunar (Daha Büyük Metin ... Daha Fazla Alan). Bu boyutlar yazıyı ve pencereleri daha büyük ama keskin gösterir, monitörün tam yenileme hızında. Siz açmadıkça kapalıdırlar.

  1. In IntelXe Manager, open the Display page.
  2. Press Turn HiDPI modes on.
  3. Restart.
  4. Choose a size in System Settings > Displays.

To turn them off, press Turn HiDPI modes off on the same page, then restart.

  1. IntelXe Manager'da Ekran sayfasını açın.
  2. HiDPI modlarını aç'a basın.
  3. Yeniden başlatın.
  4. Sistem Ayarları > Ekranlar'dan bir boyut seçin.

Kapatmak için aynı sayfada HiDPI modlarını kapat'a basın, sonra yeniden başlatın.

In Terminal, in the package folder:

  1. See what is set now: 
    ./hidpi.sh               # what is set now
  2. Turn the modes on: 
    sudo ./hidpi.sh --on     # NVRAM intelxefb-hidpi=1, a display override with the HiDPI sizes, DisplayResolutionEnabled
  3. Restart.
  4. Choose a size in System Settings > Displays.

To turn them off, run this, then restart:

sudo ./hidpi.sh --off    # takes back only what --on wrote

Terminal'de, paket klasöründe:

  1. Şu an ne ayarlı olduğuna bakın: 
    ./hidpi.sh               # şu an ne ayarlı
  2. Modları açın: 
    sudo ./hidpi.sh --on     # NVRAM'de intelxefb-hidpi=1, HiDPI boyutlarını içeren bir ekran ayarı, DisplayResolutionEnabled
  3. Yeniden başlatın.
  4. Sistem Ayarları > Ekranlar'dan bir boyut seçin.

Kapatmak için bunu çalıştırın, sonra yeniden başlatın:

sudo ./hidpi.sh --off    # yalnızca --on'un yazdıklarını geri alır

Your monitor already has an override from another tool (one-key-hidpi and the like)? Then hidpi.sh leaves it alone and stops: remove it first.

A size that leaves the screen black: HiDPI problems.

Monitörünüz için başka bir aracın (one-key-hidpi vb.) yazdığı bir ayar zaten var mı? O zaman hidpi.sh ona dokunmaz ve durur: önce o ayarı kaldırın.

Ekranı siyah bırakan bir boyut seçtiyseniz: HiDPI sorunları.

Which sizes, and how they workHangi boyutlar, nasıl çalışıyor

On a 2560x1440 monitor the sizes are 2048x1152, 1920x1080, 1706x960, 1600x900 and 1280x720. They run at the monitor's full refresh rate (180 Hz and Variable on the test monitor): macOS draws at twice the size and the GPU scales each frame down to the panel.

The override goes where other HiDPI tools put theirs (/Library/Displays/Contents/Resources/Overrides).

2560x1440 bir monitörde boyutlar 2048x1152, 1920x1080, 1706x960, 1600x900 ve 1280x720. Bu boyutlar monitörün tam yenileme hızında çalışır (test monitöründe 180 Hz ve Değişken): macOS görüntüyü iki kat büyük çizer, GPU da her kareyi panelin çözünürlüğüne küçültür.

Ekran ayarı, diğer HiDPI araçlarının kullandığı yere yazılır (/Library/Displays/Contents/Resources/Overrides).

  1. In IntelXe Manager, open the Monitor page.
  2. Turn Show in the menu bar on.
  3. To keep it in the menu bar, turn Open at login on, on the Power and app page.

The setup assistant's last page offers it too, with the other extras. It is off unless turned on.

It shows frames, the GPU clock and temperature at a glance. It lists the main display's "looks like" sizes at the current refresh rate (the HiDPI ones included): one click switches. It also has game mode: turn it on or off, or count the app in front as a game.

Game mode is off unless turned on. While a game is in front, the GPU's lowest clock goes up, 2400 MHz by default. A game is an app in the games category, or one added from the menu bar item.

  1. IntelXe Manager'da İzleme sayfasını açın.
  2. Menü çubuğunda göster seçeneğini açın.
  3. Menü çubuğunda kalsın istiyorsanız Güç ve uygulama sayfasında Girişte aç'ı açın.

Kurulum yardımcısının son sayfası da onu diğer eklerle birlikte sunuyor. Siz açmadıkça kapalı kalır.

Kare hızını, GPU saatini ve sıcaklığı bir bakışta gösterir. Ana ekranın o anki yenileme hızındaki "gibi görünür" boyutlarını (HiDPI olanlar dahil) listeler: tek tıkla geçersiniz. Oyun modunu da içerir: açıp kapatabilir, öndeki uygulamayı oyun olarak sayabilirsiniz.

Oyun modu da siz açmadıkça kapalıdır. Önde bir oyun varken GPU'nun en düşük saat hızı yükseltilir, varsayılan olarak 2400 MHz'e. Oyun, oyun kategorisindeki bir uygulama ya da menü çubuğu öğesinden eklenen bir uygulamadır.
