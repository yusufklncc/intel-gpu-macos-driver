macOS 15 SequoiamacOS 15 Sequoia

macOS 15 Sequoia gets its own package, built from the same sources as the Tahoe package. It has not been re-tested on Sequoia: read this page before you choose it.macOS 15 Sequoia'nın kendi paketi var; Tahoe paketiyle aynı kaynaktan derlendi. Sequoia'da yeniden denenmedi: seçmeden önce bu sayfayı okuyun.

Not re-tested on Sequoia. This package is built from the same sources as the Tahoe package, which was tested on one machine (an Arc B580 in a Z790 desktop, macOS 26.7.1, OpenCore); only NMXAccel is built for macOS 15. The same machine ran the previous build of this stack on macOS 15 until 4 November 2026.

Sequoia'da yeniden denenmedi. Bu paket, tek makinede denenen Tahoe paketiyle (Z790 masaüstü, Arc B580, macOS 26.7.1, OpenCore) aynı kaynaktan derlendi; yalnızca NMXAccel macOS 15 için derlendi. Aynı makine, bu yığının bir önceki derlemesini 4 Kasım 2026'ya kadar macOS 15'te çalıştırdı.

The package and the stepsPaket ve adımlar

The steps are those of this guide, with intel-gpu-macos-driver-0.1.6-sequoia.zip in place of the -tahoe.zip.

Adımlar bu rehberdekilerin aynısı; -tahoe.zip yerine intel-gpu-macos-driver-0.1.6-sequoia.zip.

IntelXe Manager (macOS 15 or later) downloads the package for your macOS by itself.

IntelXe Manager (macOS 15 ya da sonrası) macOS'unuza uygun paketi kendisi indiriyor.

In Terminal:

Terminal'de:

cd ~/Downloads
curl -LO https://github.com/yusufklncc/intel-gpu-macos-driver/releases/download/v0.1.6/intel-gpu-macos-driver-0.1.6-sequoia.zip
ditto -x -k intel-gpu-macos-driver-0.1.6-sequoia.zip .
cd intel-gpu-macos-driver-0.1.6-sequoia

The -efi.zip (IntelXe.kext, SSDT-ARCOFF.aml, HybridPM.kext, the Windows EFI script) and IntelXe Manager for Windows are the same for both macOS versions, and so are stages 1, 2 and 4.

-efi.zip (IntelXe.kext, SSDT-ARCOFF.aml, HybridPM.kext, Windows EFI betiği) ve Windows için IntelXe Manager iki macOS sürümü için de aynı; 1., 2. ve 4. aşamalar da.

What differs from TahoeTahoe'dan farkları

  • Nothing measured. The performance figures, the tested apps and the "tested on" notes in this guide are from macOS 26.7.1.
  • OpenGL through Zink was not tested on macOS 15 (Optional extras).
  • ACPI tables in the report: macOS 26 stopped publishing them; before it, the macOS report's --acpi collects the DSDT and SSDTs from the I/O Registry (Send a report).
  • The Tahoe-only notes of the boot guard (the monitor staying on the Apple logo, nvram -d leaving the variable) were observed on macOS 26; sudo nvram intelxe-accel-off=ok and Reset NVRAM work on every version (the boot guard).
  • Hiçbir şey ölçülmedi. Bu rehberdeki performans değerleri, denenen uygulamalar ve "denendi" notları macOS 26.7.1'den.
  • Zink ile OpenGL macOS 15'te denenmedi (İsteğe bağlı ekler).
  • Rapordaki ACPI tabloları: macOS 26 onları yayımlamayı bıraktı; öncesinde macOS raporunun --acpi seçeneği DSDT ve SSDT'leri I/O Registry'den topluyor (Rapor gönderin).
  • Açılış korumasının Tahoe'ya özgü notları (monitörün Apple logosunda kalması, nvram -d'nin değişkeni silmemesi) macOS 26'da görüldü; sudo nvram intelxe-accel-off=ok ve Reset NVRAM her sürümde çalışıyor (açılış koruması).

If you run 0.1.6 on Sequoia, whether it works or not, please send a report: it is the only way this page gets a "tested".

0.1.6'yı Sequoia'da çalıştırırsanız, çalışsa da çalışmasa da lütfen bir rapor gönderin: bu sayfanın "denendi" diyebilmesinin tek yolu bu.
